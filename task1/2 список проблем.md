# Проверка соблюдения мер по защите данных

**Обозначения уровней критичности:**

* **Критическая**: Прямая угроза для бизнеса или несоответствие законодательству
* **Высокая**: Значительное влияние на бизнес-процессы
* **Средняя**: Технические неполадки, требующие устранения

## 1. Процесс регистрации пациентов

| Проблема                                                                  | Критичность |
| ------------------------------------------------------------------------- | ----------- |
| Отсутствие контроля операций с персональными данными                      | Высокая     |
| Риск утечки персональных данных через сотрудника ресепшена                | Высокая     |
| Использование незашифрованных Excel-файлов для хранения данных пациентов  | Критическая |
| Отсутствие ролевого разграничения доступа (RBAC) к информации о пациентах | Критическая |

## 2. Процесс записи пациентов

| Проблема                                                               | Критичность |
| ---------------------------------------------------------------------- | ----------- |
| Отсутствует контроль за обработкой персональных данных                 | Высокая     |
| Персональные данные сохраняются в незашифрованных Excel-файлах журнала | Критическая |
| Нет ролевого разграничения доступа (RBAC) к данным пациентов           | Критическая |
| Нет ролевого разграничения доступа (RBAC) к журналу записей            | Критическая |

## 3. Процесс приема пациентов

| Проблема                                                                     | Критичность |
| ---------------------------------------------------------------------------- | ----------- |
| Потеря назначений из-за отсутствия интеграции систем                         | Высокая     |
| Устаревшая информация в медицинских картах                                   | Высокая     |
| Диагнозы не сопровождаются электронной подписью                              | Средняя     |
| Врачи имеют доступ ко всем медицинским картам пациентов                      | Критическая |
| Врачи могут видеть результаты анализов всех пациентов                        | Критическая |
| Нет ролевого разграничения доступа (RBAC) к медицинской информации пациентов | Критическая |

## 4. Процесс выполнения лабораторных анализов

| Проблема                                                         | Критичность |
| ---------------------------------------------------------------- | ----------- |
| Ошибки при ручном вводе результатов лабораторных исследований    | Высокая     |
| Отсутствие проверки достоверности данных от лаборатории          | Средняя     |
| Общедоступные файлы с результатами медицинских анализов          | Критическая |
| Общий доступ сотрудников к результатам лабораторных исследований | Критическая |
| Передача лабораторных данных без использования шифрования        | Критическая |

## 5. Процесс оплаты медицинских услуг

| Проблема                                                        | Критичность |
| --------------------------------------------------------------- | ----------- |
| Дублирование данных между системами 1С и Excel                  | Средняя     |
| Избыточные права доступа у бухгалтеров в системе 1С             | Высокая     |
| Общий доступ сотрудников к финансовым данным                    | Критическая |
| Файловый режим работы системы 1С с высоким риском утраты данных | Критическая |
| Отсутствует разграничение прав (RBAC) для Excel-файлов          | Критическая |

## 6. Процесс учета денежных средств

| Проблема                                                            | Критичность |
| ------------------------------------------------------------------- | ----------- |
| Дублирование информации между 1С и Excel-файлами                    | Средняя     |
| Избыточный уровень доступа у бухгалтеров в системе 1С               | Высокая     |
| Общий доступ сотрудников к данным в сетевом хранилище               | Критическая |
| Файловый режим работы системы 1С, создающий риски потери информации | Критическая |
| Отсутствие RBAC для доступа к Excel-файлам                          | Критическая |

## 7. Процесс учета ТМЦ

| Проблема                                                   | Критичность |
| ---------------------------------------------------------- | ----------- |
| Нет должного разграничения прав для работников склада      | Высокая     |
| Файловый режим работы 1С, создающий риск потери информации | Критическая |

## Общие проблемы по всем процессам

| Проблема                                                                                                  | Критичность |
| --------------------------------------------------------------------------------------------------------- | ----------- |
| Передача данных методом копирования файлов                                                                | Высокая     |
| Конфликты при одновременном редактировании файлов несколькими пользователями                              | Высокая     |
| Отсутствие ролевого разграничения доступа (RBAC)                                                          | Критическая |
| Отсутствие резервного копирования и файловое хранение данных с риском потери/утечки информации            | Критическая |
| Недостаточная защита персональных, платежных и медицинских данных (маскирование, токенизация, обфускация) | Критическая |
